Install with Downloader (TV devices)

  1. Install the free Downloader app (Amazon Appstore on Fire TV, Google Play on Android TV).
  2. Allow Downloader to install apps — Fire TV: Settings → My Fire TV → Developer options; Android TV: Settings → Apps → Security & restrictions → Unknown sources.
  3. Open Downloader, type 4708991 and press Go.
  4. Press Install, then Open, and sign in with your own playlist.

On phones and tablets: tap APK ⬇, open the downloaded file and allow "install unknown apps" when asked.
